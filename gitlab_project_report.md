### What is this project?

**Jacto Drones OS v0.1** is a university capstone project (INTELI — Instituto de Tecnologia e Liderança) developed by Group G04. It is a **prototype of a Continuous Delivery Operating System for drone software** — unifying the development workflow for firmware, digital platforms, and data systems. The system automates recurring task management activities, engineering rituals, and establishes standardized quality criteria and operational metrics (DORA Metrics).

The project covers:
- **CI/CD pipeline** configuration (GitLab CI) with quality gates, SAST, deploy stages
- **PX4 SITL** (Software In The Loop) drone simulation integration
- **Operational dashboards** (Next.js) for QoS, QoP, and managerial metrics
- **Process documentation** aligned with ISO 10746 and engineering best practices

## CI/CD Pipeline

The project uses **GitLab CI** with a modular `include`-based architecture:

- **`.gitlab-ci.yml`** — Main entry point
- **`ci/deploy.yml`** — CD deploy stages (6 stages: lint, build, test, SITL, deploy, release)
- **`ci/quality-gates.yml`** — Quality gates enforcement (coverage, SAST, DORA metrics)
- **`ci/sast.yml`** — Static Application Security Testing (Semgrep)
- **`ci/mr-kpis.yml`** — Automated KPI comments on MRs
- **`ci/sitl-metrics.yml`** — PX4 SITL metrics collection

### Quality Gates
The pipeline enforces:
- Code coverage thresholds
- SAST scan results
- DORA metrics tracking
- Human approval gate for main branch merges
